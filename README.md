**SFML Game Development** — Artur Moreira, Henrik Vogelius Hansson, and  Jan Haller (Packt Publishing, 2013).
ISBN 978-1-84969-684-5

This book served as a learning resource and design reference. The following parts are adapted from its examples and modified for our project:

- Game loop and fixed time step (Chapter 1)  
- Resource management (Chapter 2)
- Scene graph, scene nodes, entities, sprite nodes and the world and view (Chapter 3)  
- State stack, states and application class (Chapter 5)  

They have been modified to fit the requirements of our project.
