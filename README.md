# References and Acknowledgements

**SFML Game Development** — Artur Moreira, Henrik Vogelius Hansson, and  Jan Haller (Packt Publishing, 2013).

This book served as a learning resource and design reference during development. In particular, its examples and implementations of resource management (Chapter 2), scene graphs and scene nodes, world organization (Chapter 3), and states and state stack (Chapter 5) significantly influenced our project.

Our implementation has been adapted to the specific requirements of our game.
